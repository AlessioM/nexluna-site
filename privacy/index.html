Nexluna: Code Orbit — Privacy Policy

Last updated: 2026-10-15

Nexluna: Code Orbit ("the game") is developed by Classic Forest Games.

Data collection and sharing

The current release does not collect, transmit, sell, or share personal or sensitive user data. It contains no advertising SDK, analytics SDK, user accounts, or developer-operated online service.

Campaign progress, ship programs, settings, the pilot name you choose, and rival codes you paste are stored only on your device. The game does not send them to the developer or to a third party.

When you choose to copy or paste a challenge code, the game uses your device clipboard. A share code contains the pilot name and ship program chosen by its creator. The game does not transmit the code: you decide whether and where to send it using another app.

Browser version

The game can also be played in a web browser at https://alessiom.github.io/nexluna-site/play/. The browser version stores the same game data in your browser's local storage (IndexedDB) on your device; it is not sent to the developer. When you use a Paste or Import button, the browser may ask for permission to read your clipboard; the game only reads it at that moment.

The website and the browser version are hosted on GitHub Pages. Like any web host, GitHub may process technical data such as your IP address to deliver and secure the site; see the GitHub Privacy Statement (https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement). The website and the browser version use no cookies, analytics, or third-party trackers.

Retention and deletion

Local game data remains on your device until you reset progress in the game, clear the app's data, uninstall the game, or (browser version) clear the site data in your browser. Because the developer never receives this data, there is no server-side copy to retrieve or delete.

Security

The game does not transmit user data over a network. Protect access to your device and review a challenge code before sharing it if you consider the pilot name private.

Children

The game is not directed at children under 13.

Changes to this policy

This policy will be updated before any release that adds advertising, analytics, online services, or other data handling. The current version and effective date will remain available at the public privacy-policy URL listed on Google Play.

Contact

For privacy questions, contact Classic Forest Games at classic.forest.games@gmail.com.
