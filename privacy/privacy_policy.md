# Nexluna: Code Orbit — Privacy Policy

Last updated: 2026-10-11

Nexluna: Code Orbit ("the game") is developed by Alessio Montuoro.

## Data collection and sharing

The current release does not collect, transmit, sell, or share personal or sensitive user data.
It contains no advertising SDK, analytics SDK, user accounts, or developer-operated online
service.

Campaign progress, ship programs, settings, the pilot name you choose, and rival codes you paste
are stored only on your device. The game does not send them to the developer or to a third party.

When you choose to copy or paste a challenge code, the game uses your device clipboard. A share
code contains the pilot name and ship program chosen by its creator. The game does not transmit
the code: you decide whether and where to send it using another app.

## Retention and deletion

Local game data remains on your device until you reset progress in the game, clear the app's data,
or uninstall the game. Because the developer never receives this data, there is no server-side
copy to retrieve or delete.

## Security

The game does not transmit user data over a network. Protect access to your device and review a
challenge code before sharing it if you consider the pilot name private.

## Children

The game is not directed at children under 13.

## Changes to this policy

This policy will be updated before any release that adds advertising, analytics, online services,
or other data handling. The current version and effective date will remain available at the public
privacy-policy URL listed on Google Play.
